# Start here

From a board in its box to a board you can use: six short steps, one page each.

<div class="grid cards steps" markdown>

-   :material-numeric-1-circle:{ .lg } **[Check you have the right board](right-board.md)**


    One command tells you whether this firmware fits your board.

-   :material-numeric-2-circle:{ .lg } **[Gather what you need](what-you-need.md)**


    A card, a card reader, a mains USB charger, and an attenuator before anything transmits.

-   :material-numeric-3-circle:{ .lg } **[Put the firmware on a card](write-the-card.md)**


    Download the latest release and write it, from Linux or Windows.

-   :material-numeric-4-circle:{ .lg } **[Connect and find the board](connect.md)**


    Two USB cables, one minute, then `192.168.2.1` or `fishball.local`.

-   :material-numeric-5-circle:{ .lg } **[Check what it runs](check-the-firmware.md)**


    Confirm the board booted the firmware you wrote.

-   :material-numeric-6-circle:{ .lg } **[Before you transmit](before-you-transmit.md)**


    Four rules that keep the receiver and the bench intact.

</div>
