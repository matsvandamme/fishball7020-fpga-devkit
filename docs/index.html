Why the documentation is not here

Everything under docs/ is Markdown, and GitHub renders Markdown properly while this site would hand you the raw file. So the prose lives in the repository; this site exists for the one thing that has to be a web page.

Built against Vivado / Vitis 2022.2 on Ubuntu 22.04. Every measured number in the course came off one board, with its conditions attached.
