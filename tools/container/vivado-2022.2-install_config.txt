#### Vivado ML Standard Install Configuration ####
# For a batch install with no display (macOS, a server, CI):
#     ./devkit container install <installer.bin> -a XilinxEULA,3rdPartyEULA -b Install \
#         -c tools/container/vivado-2022.2-install_config.txt
# The -a flag accepts AMD's licence agreements on your behalf, so read them
# first. Destination below must be where the container mounts Vivado, which is
# $XILINX_DIR: edit it if that is not /tools/Xilinx (nothing rewrites this file).
# This is what `xsetup -b ConfigGen` writes for "Vivado", "Vivado ML Standard",
# with every device family switched off except Zynq-7000 - the only one this
# board needs, and the difference between ~130 GB and ~30 GB on disk.
